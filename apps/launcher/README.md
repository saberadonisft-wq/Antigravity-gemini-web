# Desktop Launcher

Ba màn hình: **Tài khoản · Đoạn chat · Kết nối**, giao diện sáng.

Chạy từ gốc dự án: `npm run launcher`. Native owner: `npm run native:launch`.

Xem [cài đặt dự án](../../README.md), [ghép hồ sơ Chrome](../../docs/CHROME_PROFILE_CONNECTOR.md) và [kiểm thử](../../docs/README.md#kiểm-thử-khi-sửa-mã).
